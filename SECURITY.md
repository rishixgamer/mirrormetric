# Security policy

## Reporting

Please use the repository’s **Security → Report a vulnerability** private
advisory flow. Do not include facial photographs, exported sessions,
passphrases, landmarks, browser-profile data, or other sensitive information
in public issues.

## Supported version

Security fixes target the latest tagged beta. Older prereleases may not receive
patches.

## Scope

High-priority findings include photo or landmark network disclosure, history
decryption without the passphrase, export plaintext leakage, unsafe model
replacement, CSP bypass, persistent passphrase material, or cross-record
deletion. Local compromise of an already unlocked device/browser remains
outside the application’s protection boundary but should still be documented
if the product worsens exposure.
