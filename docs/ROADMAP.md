# Roadmap

## `v1.0.0-beta.1` — evidence-first public beta

- [x] Dedicated landing, analysis, results, history, methodology, privacy,
  terms, and open-source views.
- [x] Adult, photo-permission, and limitation confirmation.
- [x] One-photo quick and three-photo precision modes.
- [x] Strict capture gates, multiple-face detection, pose, and expression cues.
- [x] 18 versioned front-view candidate measurements.
- [x] Perturbation sensitivity, confidence, uncertainty, and stability.
- [x] Accessible correction editor with dragging, keyboard controls, undo, and
  reset.
- [x] Optional user-chosen goal profiles with visible bands and weights.
- [x] Reversible guidance and universal professional-safety education.
- [x] Passphrase-encrypted, opt-in local history and local exports.
- [x] Lazy worker inference, self-hosted assets, checksums, and offline cache.
- [x] Unit, desktop browser, mobile browser, WCAG, and offline journeys.
- [x] Benchmark metric contract and WFLW/300W annotation adapters.
- [ ] Real WFLW/300W detector baseline under dataset terms.
- [ ] Participant repeatability study and independent annotations.

## Validation release

- Complete dataset landmark mapping review and freeze the first real baseline.
- Recruit consenting adults for same-session, different-day, and
  different-camera repeatability.
- Publish inter-rater error, limits of agreement, camera-family results, and
  powered subgroup uncertainty.
- Promote only measurements that pass the published repeatability gates.

## Explicitly outside this beta

- Side-profile measurement
- Skin or health diagnosis
- Generative appearance simulation
- Conversational “FaceGPT” advice
- Celebrity or public-figure rankings
- Personalized medical or surgical recommendations
- Cloud accounts, sync, or photo storage
- Hidden gender- or ethnicity-conditioned scoring
